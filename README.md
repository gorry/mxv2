# ◇mxv2

mxv2 - MDX player

## これはなに？

X68000 の音楽データ (MDXファイル) を鳴らして、その様子を眺めるアプリです。

## Windowsの実行方法

mxv2.exe をエクスプローラ、またはコマンドラインから実行します。

> mxv2 [input MDX file]

[input MDX file]は、演奏するMDXファイルです。指定しない場合は、最後に演奏したMDXファイル（初回起動時は、同梱MDXファイル）を演奏できる状態で起動します。

PDXファイルは、MDXと同じフォルダか、[mxv2 の設定]ダイアログから指定するPDXファイルのフォルダに収める必要があります。

## macOSの実行方法

macOS 11 以降に対応しています。Release から自分のMacに合う
`mxv2-macos-arm64-notarized.zip`（Apple Silicon）または `mxv2-macos-x86_64-notarized.zip`（Intel）を
DL/展開し、`mxv2.app` をアプリケーションフォルダなどへコピーして起動します。

MDX はウィンドウにドラッグ＆ドロップするか、Finder の「このアプリケーションで開く」から
`mxv2.app` を選んで再生できます。PDX は MDX と同じフォルダか、設定の [PDX の探索先] に
配置してください。[ファイルシステムの設定…] → [追加…] → [参照…] では
macOS 標準のフォルダ選択ダイアログを使えます。
LZX 圧縮された MDX / PDX は未対応です。

設定・追加スキン・`font.ttf` の保存先は `~/Library/Application Support/mxv2/` です。
同梱素材は `.app/Contents/Resources/` にあり、アプリ内へ書き込む必要はありません。

ターミナルからも実行できます。ビルド手順と Actions の説明は [BUILD.md](BUILD.md) を参照してください。

```sh
/Applications/mxv2.app/Contents/MacOS/mxv2 /path/to/song.mdx
```

Chromecast、Bluetooth 出力先の自動検出・遅延計測、macOS のメディア操作連携はMacOS版にはありません。

## Androidの実行方法

APKをインストールして起動します。インストール直後は、同梱MDXファイルが開けるようになっており、すぐ演奏を楽しむことができます。

ストレージにある自分のMDXライブラリを演奏したい時は、以下のようにします。

1. メニューから[ファイルシステムの設定…]を選びます。
2. [追加…]で、MDXライブラリのフォルダを指定します。
3. 「mxv2でフォルダを開いてもよいか」を尋ねられます。許可を与えると、mxv2がそのフォルダを開けるようになります（「Androidの権限とWindowsのファイアウォールについて」を参照）。
4. PDXフォルダを指定したい時は、メニューから[mxv2 の設定]を開き、[演奏]グループの[PDX の探索先]の[編集…]でPDXフォルダを追加します。複数のフォルダを登録でき、MDXファイルと同じフォルダ（と、そのファイルシステムのルートの`pdx/`）で見つからなかったときに上から順に探します。

ファイルマネージャなどで拡張子`.mdx`のファイルを開いて、mxv2で演奏することもできます（「Androidの権限とWindowsのファイアウォールについて」を参照）。

演奏中にホームへ戻ると、曲名・状態・演奏時間を小窓（ピクチャー・イン・ピクチャー）で表示し続けます（Android 8.0以降で、小窓に対応した端末のみ）。

- 小窓をタップすると、[前の曲][一時停止/再開][次の曲]のボタンが出ます。小窓を広げると元の画面に戻ります。小窓を閉じても演奏は続きます（止めるときは通知から）。
- 小窓にするかどうかは、[mxv2 の設定]の[画面]グループの[小窓で表示]で選べます（[しない]/[演奏中だけ]/[常に]。既定は[演奏中だけ]）。
- メニューの[表示]→[小窓で表示]で、その場で小窓にすることもできます。

## スキンについて

mxv2では、6種類のスキンが内蔵されており、切り替えることで表示内容を変更することができます。

- **Default**: デスクトップ（Windows）でのデフォルトスキンです。先代mxvを踏襲しています。
- **Default-Midnight**: Defaultの色変えバージョンです。
- **Default-Landscape**: デスクトップ（Windows）で横表示に適したスキンです。
- **Default-Portrait**: デスクトップ（Windows）で縦表示に適したスキンです。
- **Phone**: スマートフォン（Android）での縦表示に適したスキンです。
- **Phone-Landscape**: スマートフォン（Android）での横表示に適したスキンです。

Android版では、縦横のリアルタイムなスキンの切り替えを行うことができます。

Windows版では、スキンエディタ（SkinEditor.exe）が付属しています。既存スキンの改造や、新しいスキンを作成することができます。詳細は、README_SkinEditor.md をご覧ください。

## 仮想ファイルシステムについて

mxv2では、さまざまな形態で設置されたMDXファイルを演奏するため、内部で仮想ファイルシステムを構築しています。現在は、以下のファイルシステムを扱うことができます。

- **同梱アセット**: 後述する、同梱MDXファイルを収めるためのファイルシステムです。
- **ローカルファイルシステム**: Windowsでは普通のドライブ、macOSでは `/` をルートに、ユーザーの権限で読めるフォルダを扱います。
- **ユーザーフォルダ(UserDir)**: 各OSでの、アプリが持つユーザー向けフォルダです。
  - **Windows**: `C:\Users\GORRY\AppData\Roaming\mxv2` などに対応します。
  - **Android**: `/Android/data/net.gorry.mxv2/files/` に対応します。
  - **macOS**: `~/Library/Application Support/mxv2/` に対応します。
- **SAF**: Androidで使用する、Storage Access Framework下のフォルダです。
- **ブックマーク**: 上記各フォルダへのショートカットを登録したフォルダです。

## フォントについて

mxv2では、フォントとして MPLUS1p-Regular.ttf （M PLUS 1p）を同梱しています。このフォントは主にGUIに使われますが、ファイラー（および曲名）にも使用されます。ただしこのフォントは等幅ではなく、またX68000で使用されていたShift_JIS（おおむねCP932）の全グリフを含んでいないため、ファイラーの表示としては再現性が十分でないという欠点があります。より再現性の高いフォントをファイラーに使用したい場合は、以下のようにします。

1. 等幅でCP932全グリフを含んでいるフォントファイルを用意します。例えば「HackGen/プログラミングフォント 白源」（https://github.com/yuru7/HackGen）などがあります。
2. 当該のフォントを、ユーザーフォルダ（UserDir）に「font.ttf」という名前で配置します。

また、スキンにはフォントを内蔵することができます。内蔵されている場合は、それがファイラーのフォントとなります。

## 更新チェックについて

mxv2は、新しいバージョンが公開されているかをGitHubに1日1回問い合わせます（Windows版・Android版）。

- 確認は、起動してアプリが使える状態になった後（初回起動時はチュートリアルを終えた後）に行います。
- 新しいバージョンが公開されていれば、ダイアログでお知らせします。[リリースページを開く]で、ブラウザでGitHubのリリースページを開きます。
- 確認に失敗した場合（ネットワークにつながっていない、など）は、何もお知らせしません。次の確認は24時間後です。

設定は、[mxv2 の設定]ダイアログの[通信]グループで行います。

- **[更新チェックを行う]**: 1日1回の確認を行うかどうかを選びます。初期状態ではONです。OFFにすると、自動の確認は行いません。
- **次の更新チェック**: 次に確認を行う時刻を表示します。
- **[今すぐ更新チェックを行う]**: 24時間の間隔を待たずに、すぐ確認します。この場合は、最新のバージョンだったときや、確認に失敗したときも、結果をダイアログでお知らせします。

## キャストについて

mxv2の画面と音を、同じネットワークにあるChromecast（Google Cast対応のTVなど）へ送ることができます（Windows版・Android版）。

1. メニューの[表示]→[キャスト…]（またはF9キー）で、[キャスト]ダイアログを開きます。
2. 見つかった送り先の一覧から選んで、[送る]を押します。画面の無い機器（スマートスピーカーなど）は一覧に出ません。
3. やめるときは、[キャスト]ダイアログの[キャストを終了]を押します。

- 送り先には、mxv2の画面（ダイアログやメニューを含む）と音が数秒遅れて出ます。操作は手元のmxv2で行ってください。スマートフォンの画面をまるごと映すキャストと違い、ほかのアプリの通知などは映りません。
- **[キャスト品質]**: 送る映像の大きさ・なめらかさ・画質を、以下から選びます。初期状態は Android 版が「低」、Windows 版が「中」です。上げるほど CPU を使うので、送り先で映像がカクつくときは下げてください。送っている間は変えられません。
  - 最低（640x360・15fps）
  - 低（854x480・30fps）
  - 中（1280x720・30fps）
  - 高（1920x1080・30fps）
  - 最高（1920x1080・60fps）
- **[送っている間は手元の音を消す]**: 送り先と手元の音が数秒ずれて二重に聞こえるのを防ぎます。初期状態ではONです。
- **[映像を早める]**: 送り先で、鍵盤の動きが音より遅れて見えるときに調整します。変えた分は、送り先へは数秒後に反映されます。
- Android版では、ホームへ戻っても音を送り続けます（送り先の画面は最後の絵のままになります）。
- 送り先のリモコンで一時停止・再開すると、mxv2も一時停止・再開します。送り先のリモコンの停止ボタンや、送り先でほかのアプリに切り替えたときは、mxv2を一時停止してキャストを終えます。
- Windows版で初めて使うときは、Windowsのファイアウォールが通信の許可を求めてきます（「Androidの権限とWindowsのファイアウォールについて」を参照）。

## Androidの権限とWindowsのファイアウォールについて

### Androidの権限

mxv2は、以下の許可を求めます。

- **通知**（Android 13以降）: 初回起動時に尋ねます。演奏中の通知（曲名と、[前の曲][一時停止/再開][次の曲][停止]のボタン）を出すために使います。許可しなくても演奏はできますが、通知からは操作できなくなります。あとから変えるときは、端末の設定の[アプリ]→[mxv2]→[通知]で行います。
- **フォルダへのアクセス**: SAF（ストレージ アクセス フレームワーク）で、フォルダごとに許可を求めます。尋ねられるのは、次の2つの場合です。
  - [ファイルシステムの設定…]の[追加…]でフォルダを指定したとき。
  - ファイルマネージャなどで開いたファイルについて、[フォルダを許可する…]を選んだとき（下記）。

  ファイルマネージャなどで拡張子`.mdx`のファイルを開くと、mxv2で演奏できます（アプリの選択肢にmxv2が出ます）。
  - 許可を与えたフォルダの中にあるファイルは、**そのフォルダを開いた状態で演奏します**。PDXファイルも同じフォルダから読みます。
  - それ以外の場所にあるファイルは、どちらで演奏するかを尋ねます。
    - **[フォルダを許可する…]**: そのファイルのあるフォルダの許可を求めます（SAFの画面が、そのフォルダを開いた状態で出ます）。許可を与えると、ファイルシステムとして追加されたうえで演奏します。**同じフォルダのPDXファイルも読めます**。
    - **[このまま演奏する]**: すぐに演奏しますが、ユーザーフォルダの`mdx/inbox/`にファイルを複製して演奏するため、**PDXファイルは鳴りません**（Androidでは、1個のファイルを開く許可だけでは隣のファイルを読めないためです）。`mdx/pdx/`や[PDX の探索先]に置いてあるPDXファイルは使われます。複製したファイルは`inbox`フォルダに残るので、不要になったら削除してください。

  [ファイルシステムの設定…]でSAFのフォルダを削除するときは、[このフォルダへのアクセス許可も取り消す]かどうかを選べます。許可を残すと、そのフォルダのMDXをファイルマネージャなどから渡されたときに、一覧へ戻して演奏します。

### Windowsのファイアウォール

キャストを使うと、送り先（Chromecastなど）がmxv2から映像と音を取りに来るため、mxv2は同じネットワークからの通信を受け付けます。そのため、初めて使うときにWindowsのファイアウォールが通信の許可を求めてきます。

- 家庭内のネットワーク（プライベート ネットワーク）で許可してください。許可しないと、送り先が映像を取りに来られず、しばらくすると「送り先が映像を取りに来ませんでした。ファイアウォールで mxv2 の通信が許可されているか確かめてください。」と表示してキャストを終えます。
- あとから許可するときは、[Windows セキュリティ]→[ファイアウォールとネットワーク保護]→[ファイアウォールによるアプリケーションの許可]で、mxv2のプライベートの欄にチェックを入れます。
- 許可は、実行ファイル（mxv2.exe）の場所ごとに記録されます。別のフォルダに置いたmxv2を起動すると、あらためて尋ねられます。

## 同梱MDXファイル

本バイナリパッケージには、ArctanX氏から配布許可を得ている「GUSA-CDg (Get Ultimate Sound Amusement with G.)」内のMDXファイルが同梱されています。Assetsフォルダに設置されており、初期状態から演奏することが可能です。
配布許可を受けているGORRYが作成するパッケージを変更しない場合は「mxv2の一部」として再配布が可能ですが、再パッケージや分離しての配布には、個別の許可が必要となります。
