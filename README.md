# ◇mxv2
mxv2 - MDX player

## これはなに？
X68000 の音楽データ (MDXファイル) を鳴らして、その様子を眺めるアプリです。

## 実行方法
mxv2.exe をエクスプローラ、またはコマンドラインから実行します。

> mxv2 [input MDX file]

[input MDX file]は、演奏するMDXファイルです。

PDXファイルは、MDXと同じフォルダか、[mxv2 の設定]ダイアログから指定するPDXファイルのフォルダに収める必要があります。

### Androidの実行方法

APKをインストールして起動します。

ストレージにある自分のMDXライブラリを演奏したい時は、以下のようにします。

1. メニューから[ファイルシステムの設定…]を選びます。
2. [追加…]で、MDXライブラリのフォルダを指定します。
3. AndroidのSAF（ストレージ アクセス フレームワーク）のルールに沿って、「mxv2でフォルダを開いてもよいか」を尋ねられます。許可を与えると、mxv2がそのフォルダを開けるようになります。
4. PDXフォルダを指定したい時は、メニューから[mxv2 の設定]を開き、[演奏]グループの[PDX の探索先]でPDXフォルダを指定します。

## スキンについて
mxv2では、6種類のスキンが内蔵されており、切り替えることで表示内容を変更することができます。

- **Default**: デスクトップ（Windows）でのデフォルトスキンです。先代mxvを踏襲しています。
- **Default-Midnight**: Defaultの色変えバージョンです。
- **Default-Landscape**: デスクトップ（Windows）で横表示に適したスキンです。
- **Default-Portrait**: デスクトップ（Windows）で縦表示に適したスキンです。
- **Phone**: スマートフォン（Android）での縦表示に適したスキンです。
- **Phone-Landscape**: スマートフォン（Android）での横表示に適したスキンです。

Android版では、縦横のリアルタイムなスキンの切り替えを行うことができます。

Windows版では、スキンエディタ（SkinEditor.exe）が付属しています。既存スキンの改造や、新しいスキンを作成することができます。詳細は、README_SkinEditor.md をご覧ください。

## 仮想ファイルシステムについて
mxv2では、さまざまな形態で設置されたMDXファイルを演奏するため、内部で仮想ファイルシステムを構築しています。現在は、以下のファイルシステムを扱うことができます。

- **同梱アセット**: 後述する、同梱MDXファイルを収めるためのファイルシステムです。
- **ローカルファイルシステム**: Windowsで使用する、普通のドライブです。
- **ユーザーフォルダ**: 各OSでの、アプリが持つユーザー向けフォルダです。
  - **Windows**: `C:\Users\GORRY\AppData\Roaming\mxv2` などに対応します。
  - **Android**: `/Android/data/net.gorry.mxv2/files/` に対応します。
- **SAF**: Androidで使用する、Storage Access Framework下のフォルダです。
- **ブックマーク**: 上記各フォルダへのショートカットを登録したフォルダです。

## 同梱MDXファイル

本バイナリパッケージには、ArctanX氏から配布許可を得ている「GUSA-CDg (Get Ultimate Sound Amusement with G.)」内のMDXファイルが同梱されています。Assetsフォルダに設置されており、初期状態から演奏することが可能です。
配布許可を受けているGORRYが作成するパッケージを変更しない場合は「mxv2の一部」として再配布が可能ですが、再パッケージや分離しての配布には、個別の許可が必要となります。
