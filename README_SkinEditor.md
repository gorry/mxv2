# ◇mxv2 スキンエディタ
SkinEditor - mxv2 skin editor

## これはなに？
mxv2 の画面の見た目を決める「スキン」を編集するアプリです。mxv2 の画面を模したプレビューを見ながら、各部品の位置や大きさ、配色、素材（ビットマップとフォント）を設定できます。

素材のビットマップそのものを描く機能はありません。画像は外部のツールで用意し、このアプリでスキンへ取り込みます。

## 動作環境
Windows 10 / 11 で動作します。.NET 8 のデスクトップランタイム（Windows Desktop Runtime）が必要です。

## 起動方法
SkinEditor.exe を、次のどちらかのフォルダで起動します。どちらのフォルダで起動したかによって、編集の対象が変わります。

| 起動するフォルダ | モード | 編集の対象 |
|---|---|---|
| mxv2.exe のあるフォルダ | ユーザーフォルダモード | ユーザーフォルダ（`%APPDATA%\mxv2\skin\`）のスキン |
| CMakeLists.txt のあるフォルダ（mxv2 の開発フォルダ） | 開発フォルダモード | mxv2 に同梱するスキン（`assets\skin\`）そのもの |

通常は **ユーザーフォルダモード** で使います。mxv2.exe と同じフォルダに SkinEditor.exe を置いて起動してください。mxv2 に同梱されているスキン（Default、Phone など）は参照のみで、直接は編集できません。同梱スキンを元にした自分のスキンを作って編集します。

どちらのフォルダでもない場所で起動すると、その旨のダイアログを表示して終了します。

コマンドラインの引数（省略可）:

> SkinEditor [-userdir <フォルダ>] [<起動フォルダ>]

- `-userdir <フォルダ>`: ユーザーフォルダモードでの編集先を差し替えます（mxv2 本体の `-userdir` と同じ）。
- `<起動フォルダ>`: assets フォルダのある場所を明示します。省略時はカレントフォルダ、次に SkinEditor.exe のあるフォルダを見ます。

作ったスキンは、mxv2 の [mxv2 の設定] ダイアログの「スキン」一覧に、名前のまま並びます。

## スキン一覧の画面
起動すると、モードと編集先のフォルダ、編集できるスキンの一覧が表示されます。

- **[開く]**: 選んだスキンを編集画面で開きます。一覧のダブルクリック、または Enter でも開けます。
- **[新規作成…]**: 新しいスキンを作ります（次の節）。
- **[スキン一覧の再読み込み]**: エクスプローラなどでスキンのフォルダを増減させたあと、一覧を読み直します。
- **[バージョン情報…]**: このアプリの名前、バージョン、ビルド日付、著作権表示を表示します。
- **[終了]**: アプリを終了します。

## 新規スキンの作成
[新規作成…] で、スキン名と「元にするスキン」を指定します。元にするスキンの扱いは 2 通りです。

- **参照する**: 元のスキンを参照先（Base）にした、差分だけを持つスキンを作ります。自分で変えた項目だけが自分のスキンに保存され、それ以外は元のスキンの値がそのまま使われます。元のスキンが更新されると、変えていない項目はそれに追従します。配色だけ変えたいときなど、たいていはこちらで十分です。
- **コピーして新規スキンにする**: 元のスキンの内容（座標・配色・素材ファイル）をすべて自分のスキンへ複製した、独立したスキンを作ります。作成した時点でディスクに書き込まれます。

スキン名はフォルダ名になります。ユーザーフォルダモードでは、同梱スキンは `assets:Default` のように `assets:` 付きで、ユーザーフォルダのスキンは名前だけで候補に並びます。

## 編集画面の構成
左がプレビュー、右が項目のタブです。上のツールバーには次のものがあります。

- **[保存 (Ctrl+S)]**: 編集中の内容をスキンのフォルダへ書き込みます。保存するまでファイルは変わりません（素材のインポートだけは例外で、その場で書き込まれます）。未保存の変更があるとタイトルに `*` が付きます。
- **参照先スキン**: このスキンが参照する Base のスキンです。ここで選び直すと参照先を切り替えます（後述）。
- **[配色を参照先スキンに戻す]**: 自分のスキンの配色（colors.ini）を捨てて、参照先の配色に戻します。
- **[素材の再読み込み]**: 外部のツールでスキンフォルダの *.bmp や font.ttf を描き換えたあと、プレビューに反映させます。

右のタブは mxv2 の画面の部品ごとに分かれています。

| タブ | 内容 |
|---|---|
| 画面 | 背景の素材、画面の宣言サイズ、ファイラーを置く辺と厚み、背景の配色 |
| フォント | 曲名とファイラーの文字に使う TrueType フォント、ステータス欄などに使うミニフォント |
| 鍵盤 | 鍵盤の素材、位置、1 オクターブぶんの鍵の X 座標、各チャンネルの Y 位置、配色 |
| ステータス | チャンネルごとのステータス欄の矩形と、項目ごとの配置（レベルメータ、配置、ピッチ LFO、音量 LFO、PCM のサブタブ）、音色データ表示の配置（音色 / 音色 2 / 音色 (PCM段) のサブタブ）、配色 |
| レジスタ一覧 | 鍵盤の長押しで出る OPM レジスタ一覧のオーバーレイの矩形、文字の位置、配色 |
| バナー | バナーの素材と矩形 |
| 操作ボタン | 操作ボタンの素材、矩形、ボタンごとの素材内位置と配置、LED のパレット、配色 |
| 音量バー | 音量バーの素材と矩形、つまみと帯の素材内位置 |
| プログレスバー | プログレスバーの素材と矩形、帯の素材内位置 |
| 曲名 | 曲名の矩形、スクロール速度、配色 |
| ファイラー | ファイラーの余白、行の高さ、ファイル名と曲名の位置、スクロール速度、配色 |
| スクロールバー | スクロールバーの素材、幅、つまみと矢印の素材内位置 |

各項目の意味は mxv2 に同梱の `assets\skin\Default\layout.ini` のコメントも参考にしてください。

## 値の編集と「継承」のチェックボックス
各行の左端にあるチェックボックスは、その項目を**自分のスキンで持つか、参照先から継承するか**を表します。

- **OFF（継承）**: 参照先のスキンの値をそのまま使います。値は表示されますが編集できません。
- **ON（自分の値）**: 自分のスキンに値を持ちます。ON にした瞬間の値はそれまでの実効値と同じなので、チェックを入れただけでは見た目は変わりません。そのあと数値を変えると自分のスキンの値になります。
- ON から OFF に戻すと、自分のスキンからその項目が消えて参照先の値に戻ります。

参照先のないスキンでは、チェックボックスは常に ON （自分の値）で操作できません。

「1オクターブの鍵のX」「各チャンネルのY位置」「PCM の各チャンネル」のように 1 つの項目を複数の行に分けて表示しているところは、グループ全体で 1 つのチェックボックスを持ちます。

数値は直接入力するか、スピンボタンで増減できます。座標は画面左上を原点としたピクセルで、ファイラー以外側の部品はその矩形の原点からの相対です。

## プレビューでの操作
- 右のタブでどれかの項目にカーソルを置くと、その項目に対応する部品がプレビュー上で白黒の枠で囲まれます。
- プレビューをクリックすると、その場所にある部品の項目へタブとカーソルが移ります。同じ場所に部品が重なっているときは、クリックするたびに次の部品へ選択が移り、最後まで行くと選択が外れます。
- 位置を持つ部品は、選択中に枠の中をドラッグすると動かせます。ドラッグ中は対応する数値欄が追従します。ドラッグで動かした時点で、その項目は自分のスキンの値（チェック ON）になります。
- 一部のタブには、プレビュー確認用のトグルやスライダがあります（鍵盤の「押す」、操作ボタンの「押す」「LED」、レベルメータの「レベル」、音量バーの「音量」、プログレスバーの「プレイ時間」、ファイラーの「大きい文字」、スクロールバーの「スクロール」「上矢印」「下矢印」）。これらは見え方を確かめるためのもので、スキンには保存されません。
- mxv2 はステータス欄を長押しすると、チャンネルごとのステータスと「音色データ」（アルゴリズム、各オペレータのパラメータ、OPM のノイズ・タイマー・LFO の値）の表示を切り替えます。音色データの各項目の位置は [ステータス] タブの [音色] / [音色 2] / [音色 (PCM段)] で設定します。これらのサブタブを選ぶとプレビューは音色データ表示（値はダミー）になり、レベルメータ〜PCM のサブタブを選ぶと従来の表示に戻ります（他のタブへ移っても表示はそのままです）。
- mxv2 は鍵盤を長押しすると、画面の上に OPM の全レジスタの値を並べたオーバーレイを出します。その矩形・文字の位置・配色は [レジスタ一覧] タブで設定します。このタブを選んでいる間だけプレビューにオーバーレイ（値はダミー）が出て、他のタブへ移ると消えます（鍵盤とステータスを覆うため）。

## 素材のインポート
各タブの上のほうにある「素材: …」の行が、そのタブの部品に使う素材ファイルです。

- 左端のチェックボックスは「自分のスキンのフォルダにそのファイルがあるか」を表します。OFF にすると自分のファイルをスキンフォルダ内の `_nouse` サブフォルダへ退避して参照先のファイルに戻し、ON にすると参照先のファイルを自分のスキンへ複製します。誤って OFF にしても元のファイルは消えません。
- **[インポート…]** で外部のファイルを選ぶと、既定のファイル名（`back.bmp` など）で自分のスキンへ複製します。状態は「あり」（自分のファイル）／「参照」（参照先のファイル）／「なし」で表示されます。
- 鍵盤・操作ボタン・レベルメータ・ミニフォントは、パレット番号で発色させる素材のため、**8bpp インデックスカラーの BMP** しか受け付けません。自動では減色しません。それ以外の素材は BMP / PNG / JPEG を受け付け、24bpp の BMP として保存します。
- インポートした素材がそれまでより小さいと、素材内の切り出し位置（Src で始まる項目）が素材の外を指すことがあります。はみ出す項目は自動で素材の範囲内に丸められます。
- 素材の大きさは自由です。背景（`back.bmp`）は宣言サイズより大きくてもよく、その高さまで画面が伸びます。
- **フォント**タブの「素材: TTFフォント (font.ttf)」では、曲名とファイラーの文字に使う TrueType フォントを取り込めます。スキンにフォントが無ければ、参照先のフォント、ユーザーフォルダの `font.ttf`、mxv2 同梱のフォントの順に使われます。

インポートしたファイルは、保存操作を待たずにその場でスキンのフォルダへ書き込まれます。

## 配色
各タブの「配色」の下に、その部品の色と濃さがあります。色のボタンを押すと色の選択ダイアログが開きます。

配色（colors.ini）は項目ごとではなくファイル単位で継承されます。どれか 1 つでも色を変えると、その時点の配色全体が自分のスキンの colors.ini として持たれます。参照先の配色に戻したいときは、ツールバーの [配色を参照先スキンに戻す] を使います。

## 参照先スキン（Base）の切り替え
ツールバーの「参照先スキン」で選び直すと、確認のうえで切り替えを実行し、**その場で保存**します（通常の編集と違い、保存操作を待ちません）。

- **参照をやめる**（「(なし)」を選ぶ）: そのとき有効になっていた値・素材ファイル・配色をすべて自分のスキンへ複製し、独立したスキンになります。
- **参照先を選ぶ／変える**: 参照先と同じ値になっている項目は自分のスキンから取り除かれ、参照先から継承する形になります。

## 保存と終了
[保存 (Ctrl+S)] で layout.ini と colors.ini を書き込みます。layout.ini には自分のスキンで持つ項目だけが書かれます（参照先から継承している項目は書かれません）。ファイルにあるコメントや空行、項目の並びは保存しても保たれ、値だけが書き換わります。

未保存の変更がある状態で編集画面を閉じると、「保存しますか？」と確認します。[はい] で保存して閉じ、[いいえ] で保存せずに閉じ、[キャンセル] で編集に戻ります。編集画面を閉じるとスキン一覧に戻ります。

## スキンのファイル構成
```
skin/<スキン名>/
    layout.ini   画面サイズ・各部品の座標・素材のファイル名。[Skin] Base=<参照先>
    colors.ini   配色（無ければ参照先の配色）
    font.ttf     文字描画に使うフォント（無ければ参照先、ユーザーフォルダ、同梱の順）
    *.bmp        素材ビットマップ（無ければ参照先のフォルダのもの）
    _nouse/      素材行のチェックを OFF にしたときに退避したファイル
```

ユーザーフォルダのスキンをほかの環境へ持っていくときは、このフォルダごとコピーします。`_nouse` は不要です。参照先に同梱スキンを使っているときは、持っていく先の mxv2 にも同じ同梱スキンが必要です。

## 注意
- ユーザーフォルダモードでは同梱スキンを編集できません。同梱スキンを元に「参照する」または「コピーして新規スキンにする」で自分のスキンを作ってください。
- 開発フォルダモードは mxv2 の同梱スキンを直接書き換えます。mxv2 のビルド環境がある場合にだけ使ってください。
- 素材ファイルの名前は既定のものに固定しています。layout.ini の `Img` で始まるキーでファイル名を変えることもできますが、このアプリからは変えられません。
